# Defense Health Agency

> The Defense Health Agency (DHA) is a joint, integrated combat support agency of the U.S.
> Department of Defense. It enables the Army, Navy, and Air Force medical services to
> provide a medically ready force and a ready medical force, and it operates the Military
> Health System (MHS) — including MHS GENESIS (the DoD electronic health record built on
> Oracle Health/Cerner Millennium), the MHS Data Repository (MDR), the MHS Management
> Analysis and Reporting Tool (M2), and the Joint Health Information Exchange.

## What an agent should know first

DHA publishes **no public developer API, no developer portal, and no machine-readable
API contract**. There is no OpenAPI, AsyncAPI, GraphQL SDL, WSDL, .proto, MCP server or
A2A agent card on any DHA host. Every named /.well-known/ discovery path on
www.health.mil, www.dha.mil and www.tricare.mil returned 404 (see the well-known probe
below). Do not attempt to construct a base URL or call an endpoint from this profile —
none is published.

What DHA does publish is a large body of **human-readable interface documentation**:
32 Interface Control Documents describing MHS Data Repository data feeds, plus MDR and M2
data dictionaries and user guides — all as .DOCX and .PDF files in the Health.mil
Reference Center.

Data access is by request, not by key: the DHA developer/service request path
(DAD IO J-6) runs on info.health.mil, which requires a Common Access Card and is served
under a DoD-internal PKI certificate that does not chain to any public root.

## Known API surface

- [MHS GENESIS SMART on FHIR](https://www.health.mil/Military-Health-Topics/Technology/MHS-GENESIS): The DoD electronic health record exposes a SMART on FHIR interface for authorized clinical applications. Access is restricted to vetted DoD application partners. No service root URL, capability statement, scope list or SMART configuration document is published; MHS GENESIS is absent from Oracle Health's public patient-access FHIR endpoint directory.

## Documentation

- [MHS GENESIS: The Electronic Health Record](https://www.health.mil/Military-Health-Topics/Technology/MHS-GENESIS): Program overview of the DoD EHR serving 9.5 million beneficiaries.
- [Health.mil Technology](https://www.health.mil/Military-Health-Topics/Technology): Index of MHS technology programs — Joint HIE, MHS GENESIS, PEO DHMS, Solution Delivery Division.
